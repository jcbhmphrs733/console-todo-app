# Overview

I have had previous experience with C# but wanted to study its predecessor. I thought about wich of the GOAT projects that I could use to dip my toes in the water. I landed on the TODO list, probably because my life is so hectic and I constantly rely on my own todo list every day.

This software comes packed with a simple Todo class and a slighly more complex TodoManager. Together they allow a user to create new todos and mark them pending or completed. As well as a handy filter by completion option. The console is a bit primitive and is not the sexiest UX but it may remind some of the early era of code when programers had nothing but the console.
